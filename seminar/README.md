# Prompt Engineering in Software Development - Seminar

This folder contains the complete seminar material for **Prompt Engineering in Software Development**.

## Files

| File | Description |
|------|-------------|
| `presentation.md` | Full PPT content (20 slides) |
| `speaker-notes.md` | Detailed speaker notes for each slide |
| `presentation.html` | HTML slideshow (open in browser) |

## How to Use

1. **For PowerPoint/Google Slides:** Copy content from `presentation.md` slide by slide
2. **For HTML Presentation:** Open `presentation.html` in any browser and press arrow keys to navigate
3. **Speaker Notes:** Refer to `speaker-notes.md` while presenting

## How to Download

1. Click on the file you want
2. Click the **Download** button (or Raw → Right-click → Save As)
3. For the HTML file: Download and open in Chrome/Firefox
